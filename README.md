# Diaru — 오늘의 조각

종이 다이어리를 꾸미던 감각이 폰에서도 남을까? 사진·글·스티커를 **좌우 펼침면(1200×1000)** 위에
자유롭게 놓고, 속지를 갈아 끼우고, 파일 하나로 내보내 친구에게 보내는 꾸미기 도구.

서버도 계정도 없다. 기록은 전부 `localStorage` 에, 공유는 그림까지 data URL 로 박아 넣은
HTML 한 장으로 나간다.

## 지금 되는 것

- **시작 화면** — 켜면 `#landing` 이 먼저 뜨고 `시작하기` 를 눌러야 홈으로 간다. 로그인은 `#landing-auth` 자리에 붙인다.
- **펼침면 편집기** — 사진/텍스트/스티커를 끌어 놓고, 회전·글씨체·굵기·기울임, 왼쪽/오른쪽 페이지 선택, 확대.
- **템플릿은 없다** — 견본 대신 도구. 새 기록은 늘 빈 종이에서 시작하고, 꾸밀 거리는 서랍(속지·스티커)에서 가져온다.
- **속지(내지) 열두 무늬** — 무지·줄글·땡땡이·모눈·월간/주간 플래너·체크리스트·공책·오선지·작은 모눈·사선·삼각 격자
  + 속지 색 8종. 홈에는 앞 여섯만, 서랍에 전부.
  월간 플래너는 무늬 위에 요일 한 줄을 종이의 일부로 얹는다(조각이 아니라 `.paper-chrome`).
  무늬는 `#paper` / 피드 미리보기 / 서랍 견본이 `--pu` 한 변수로 배율만 바꿔 같은 CSS 를 쓴다.
- **스티커 아홉 화풍** — 손그림(수채) · 도트 · 레트로 · 먹선 · 젤리 · 금박 · 압화 · 도장 · 펠트, 각 16종 = 144종.
  시트 한 장이 4×4 스프라이트라 `background-position` 으로 자른다.
- **내 스티커** — 사진을 올리면 360px PNG 로 줄여 스티커가 된다(투명 PNG 그대로 유지).
- **저장하면 홈으로** — 저장은 편집기를 닫고 홈으로 돌려보낸다. 피드·알림에 바로 반영.
- **이미지로 저장** — 펼침면을 캔버스에 그대로 다시 그려 2배 크기 PNG 로 내려받는다(라이브러리 없이,
  CSS 가 쓰는 것과 같은 숫자로). 옛 HTML 공유 파일은 걷어냈다.
- **프로필 편집란** — 배경화면·인장·이름·아이디·소개를 프로필 그 자리에서 고친다.
- **친구** — 돋보기로 @아이디·이름 검색, 팔로우/해제/차단. 이름과 별개로 고유 아이디를 갖는다.
- **비공개가 기본** — 프로필은 잠겨 있고 **서로 팔로우해야 친구**. 친구에게만 소개와 기록이 열린다.
  다이어리는 그 위에 한 겹 더 — 한 장씩 「나만 보기 / 친구 공개」를 고른다(기본은 나만 보기).

## 구조

```
dist/index.html   화면 뼈대(한 장)
dist/app.js       전부. PACKS(스티커 팩) · PAPERS(속지) · 사람들 · 편집기 · 피드 · 내보내기
dist/style.css    스타일. 끝쪽에 속지 무늬 · 사람들 · 네이비×아이보리×세이지 피부 순으로 얹혀 있다
dist/assets/      stickers*.png (4×4 시트), photos/*.jpg
assets/reference/ 내가 찍은 원본 사진(.gitignore)
assets/src/       줄이기 전 1024px 원본 시트(.gitignore)
tools/gen-stickers.mjs  스티커 팩 생성 (gpt-image, 투명 배경)
tools/make-photos.mjs   레퍼런스 사진 고르고 잘라 굽기
tools/gen-icon.mjs      앱 아이콘 (로고 글꼴의 D + 금색 별)
dist/icons/             아이콘 전 크기 + manifest.webmanifest
```

스티커 팩을 새로 구우려면:

```bash
node tools/gen-stickers.mjs            # 없는 것만
node tools/gen-stickers.mjs pixel      # 하나만
node tools/gen-stickers.mjs --force    # 다시
```

새 팩을 추가하면 `app.js` 의 `PACKS` 에 `{id,name,file,blend,cells}` 를 넣고,
`style.css` 의 `.pack-<id>{--sheet:url(...)}` 한 줄을 더한다.

### 함정

- 시트는 **반드시 4×4, 셀 경계가 비어 있어야** 한다. 눈으로 보지 말고 알파를 재서 판정한다
  (투명 PNG 는 뷰어가 배경을 깔아 보여준다).
- 도트 팩은 0.75배로 줄이면 픽셀이 뭉갠다 — 1024 원본 그대로 쓴다.
- 시트 아홉 장이면 7MB 가 넘는다. 스티커 서랍은 **한 팩만 펴고 시작**하고(기본 손그림),
  '전체' 를 눌렀을 때만 전부 받는다.
- 속지 무늬의 배율 변수 `--pu` 는 **길이**여야 한다(`.093px`). `px` 를 빼먹으면 calc 가 무효가 되어
  그 무늬만 통째로 사라진다 — 타일 넷이 빈 채로 나간 적 있다.
- 앱 안의 사진은 전부 `assets/reference/` 의 내 사진에서 잘라 쓴다. AI 배경은 티가 나서 버렸다 —
  새로 고르려면 `node tools/make-photos.mjs sheet` 로 번호를 보고 `PICKS` 를 고친다.
- 친구 데이터는 아직 기기 안에만 있다. 서버가 붙을 자리는 `app.js` 의 「사람들」 절 넷:
  `saveMe/saveSocial` · `findPeople` · `friendFeed`. 화면 쪽은 손댈 게 없게 묶어 뒀다.
- 글씨체가 늦게 입혀져 한 번 바뀌던 것(FOUT)은 `display=block` + 글꼴 다 뜬 뒤 한 번에 보여주기로 막았다.
- 앱 아이콘은 `node tools/gen-icon.mjs [navy|ivory|star]` 로 다시 굽는다. 지금은 ivory.
- 속지 무늬는 `#paper` 가 `transform:scale()` 아래 있어서 줄 간격이 1px 단위로 흔들린다. 무늬를
  더 진하게 하면 그 흔들림이 같이 도드라진다.

## 다음

- 로그인(시작 화면) → 기기 간 동기화. 지금은 `localStorage` 가 전부라 브라우저를 비우면 사라진다.
- 속지 무늬를 **페이지마다** 다르게 (왼쪽 모눈 / 오른쪽 줄글).
- 내 스티커 테두리 따기 — 올린 사진의 배경을 지워 진짜 다이컷 스티커로.
- 마스킹테이프·레이스 같은 '띠' 조각(지금은 사진·글·스티커 세 종류뿐).
- 조각 겹침 순서(앞으로/뒤로)와 되돌리기.
- 친구 피드에 좋아요·댓글. 지금은 보기만 된다.
- 팔로우 요청/수락 — 지금은 맞팔이 되면 바로 친구다.
